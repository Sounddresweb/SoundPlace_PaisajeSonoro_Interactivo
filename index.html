Paisaje Sonoro Táctil

Toca una zona y escucha lo que dibuja

Cada color es un sonido. Si varias personas tocan a la vez, el jardín se mezcla.

Pulsa Esc o E para salir
Todas las zonas usan sonido sintetizado.

Prototipo hecho con p5.js para la imagen y la interacción, y con Web Audio para el sonido. Los sonidos se sintetizan en vivo, y cada zona puede usar un archivo propio: déjalo en la carpeta audio/ con el nombre de la zona (por ejemplo audio/agua.mp3) o cárgalo con el botón. Las zonas de la lista también se activan con el dedo, el ratón o el teclado (Espacio o Enter).
